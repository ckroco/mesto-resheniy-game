A browser-based interactive game that helps teenagers explore their interests, try different approaches and identify practical next steps without the pressure of choosing a profession too early.

## 1. About the Project

Mesto Resheniy (Place of Decisions) started as a physical board game developed for career guidance.

The idea was to move beyond traditional career tests and create an interactive experience where players could explore different roles, tasks and decisions.

The digital version transforms this concept into a browser-based application with interactive cards, unexpected events, limited resources and a visual decision tree.

**The goal is not to predict the perfect profession. It is to help players discover what they want to explore next.**

## 2. Key Features

- **Interactive decision tree:** choices and tokens build a visual map of interests and experiences.
- **Scenario-based cards:** players explore tasks, personal preferences and possible challenges.
- **Unexpected events:** decisions lead to different consequences.
- **Resource management:** limited opportunities for additional exploration encourage prioritisation.
- **Two game modes:** a quick session (9 cards and 2 events) and an extended session (14 cards and 3 events).
- **Personal results:** players reflect on possible directions, develop hypotheses and select a practical next step.
- **PDF export:** a personal report can be downloaded after completing the game.
- **Session recovery:** progress can be saved locally and restored in the browser.

No registration is required.

## 3. Technical Implementation

The current MVP is a lightweight, client-side web application.

| Component | Technology |
|---|---|
| Structure | HTML5 |
| Styling | CSS3 |
| Game logic | Vanilla JavaScript |
| State persistence | Browser localStorage |
| PDF generation | Client-side JavaScript and Canvas |
| Deployment | GitHub Pages |
| Architecture | Static, client-side application |

The application does not require a dedicated backend or database.

Game progress is stored locally in the user's browser. Players can also export a portable HTML copy of their current game.

The interface includes layouts for desktop and mobile devices.

## 4. Product Development

The main product challenge was translating a physical board game and career guidance methodology into a consistent digital experience.

Key areas of work:

**Product Discovery**
- Defining the audience and the problem to solve.
- Identifying the value of interactive career exploration.
- Prioritising functionality for the first working version.

**Business Analysis**
- Translating game mechanics into functional requirements.
- Defining decision rules, scenarios and state transitions.
- Structuring player choices and their consequences.

**UX and Game Design**
- Designing user journeys from onboarding to final results.
- Connecting individual decisions to the visual decision tree.
- Balancing gameplay, reflection and practical outcomes.

**Delivery and Iteration**
- Breaking down the implementation into manageable tasks.
- Testing game scenarios and interactions.
- Improving usability across devices.
- Preparing and publishing the working MVP.

Mesto Resheniy is an exploratory educational game, not a formal psychometric assessment.

It does not provide automated career predictions or replace professional career guidance.

The game encourages independent thinking, reflection and practical exploration.
