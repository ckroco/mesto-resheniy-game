# «Место решений» | Интерактивная игра для исследования профессиональных направлений

**Русский** | [English](README.md)

**Исследуй возможности. Принимай решения. Выращивай своё дерево решений.**

«Место решений» — интерактивная игра в браузере, которая помогает подросткам исследовать свои интересы, пробовать разные способы действий и находить следующие практические шаги без необходимости слишком рано выбирать профессию.

**Статус:** работающая первая версия (MVP) | Открытое тестирование

**Язык игры:** русский

### [Попробовать игру](https://ckroco.github.io/mesto-resheniy-game/)

## 1. О проекте

«Место решений» начиналось как настольная игра, разработанная для профориентации.

Идея заключалась в том, чтобы выйти за рамки традиционных тестов и создать интерактивный опыт, в котором участники исследуют разные роли, задачи и варианты решений.

Цифровая версия превращает эту идею в игру для браузера с интерактивными карточками, неожиданными событиями, ограниченными ресурсами и наглядным деревом решений.

**Цель игры — не предсказать идеальную профессию, а помочь человеку понять, что ему интересно попробовать дальше.**

## 2. Основные возможности

- **Интерактивное дерево решений:** выборы и жетоны складываются в наглядную карту интересов и полученного опыта.
- **Карточки с ситуациями и заданиями:** игрок исследует виды деятельности, собственные предпочтения и возможные трудности.
- **Неожиданные события:** разные решения приводят к разным последствиям.
- **Управление ресурсами:** ограниченное число дополнительных проб помогает расставлять приоритеты.
- **Два режима игры:** быстрая партия (9 карточек и 2 события) и расширенная партия (14 карточек и 3 события).
- **Личный результат:** игрок осмысляет возможные направления, формулирует гипотезы и выбирает следующий практический шаг.
- **Выгрузка в PDF:** после завершения игры можно сохранить персональный отчёт.
- **Восстановление партии:** прогресс сохраняется локально, и к игре можно вернуться в том же браузере.

Регистрация не требуется.

## 3. Техническая реализация

Текущая версия — лёгкое веб-приложение, логика которого выполняется на стороне пользователя.

| Компонент | Технология |
|---|---|
| Структура | HTML5 |
| Оформление | CSS3 |
| Игровая логика | JavaScript без дополнительных библиотек |
| Сохранение состояния | localStorage в браузере |
| Создание PDF | JavaScript и Canvas на стороне пользователя |
| Публикация | GitHub Pages |
| Архитектура | Статическое веб-приложение, работающее в браузере |

Приложению не нужны отдельная серверная часть и база данных.

Игровой прогресс сохраняется локально в браузере. Также игрок может выгрузить переносимую HTML-копию своей текущей партии.

Интерфейс предусматривает отображение на компьютерах и мобильных устройствах.

## 4. Разработка продукта

Основная задача заключалась в переносе механики настольной игры и профориентационной методики в согласованный цифровой сценарий.

Ключевые направления работы:

**Исследование продукта**
- Определение аудитории и задачи, которую должен решать продукт.
- Формулирование ценности интерактивного исследования профессиональных направлений.
- Определение приоритетов для первой работающей версии.

**Бизнес-анализ**
- Преобразование игровых механик в функциональные требования.
- Описание правил выбора, сценариев и переходов между состояниями.
- Структурирование действий игрока и их последствий.

**Проектирование взаимодействия и игровой механики**
- Разработка пути пользователя от первого запуска до итогового результата.
- Связь отдельных решений с визуальным деревом.
- Поиск баланса между игровым процессом, осмыслением опыта и практическими выводами.

**Реализация и последовательные улучшения**
- Декомпозиция работ на управляемые задачи.
- Проверка игровых сценариев и взаимодействий.
- Улучшение удобства использования на разных устройствах.
- Подготовка и публикация работающей первой версии.

Работающий прототип открыт для тестирования.

- Доработка игровых механик и подсказок.

Сейчас главное — проверить игровой опыт на практике, прежде чем усложнять решение дополнительными функциями.

## 7. Важное уточнение

«Место решений» — образовательная игра для исследования вариантов, а не стандартизированная психодиагностическая методика.

Она не предсказывает будущую профессию автоматически и не заменяет профессиональную консультацию по профориентации.

Игра помогает самостоятельно размышлять, замечать интересы и проверять идеи на практике.
